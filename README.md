# AI Builder Placer (Forge 1.20.1)

## Fastest Way to Get the `.jar` (No Local Setup Needed)
1. Upload these files to a free GitHub repository.
2. Click the **Actions** tab on GitHub. It will automatically compile and obfuscate the mod using `.github/workflows/build.yml`.
3. Download the compiled `aibuilder-1.0.0.jar` from the workflow **Artifacts** section.

## Or Build Locally
- **Windows:** Double-click `build_jar.bat` (requires Gradle or IntelliJ IDEA).
- **Linux:** Run `./build_jar.sh` in a terminal with Gradle and Java 17 installed.
